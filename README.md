# ValidAxis Demo

A simple web application demonstrating the functionality of the [ValidAxis npm package](https://www.npmjs.com/package/validaxis).

## Features

- Indian mobile number validation
- Indian PIN code validation
- PAN number format validation
- INR currency formatting

## Installation

```bash
npm install
```

## Run Locally

```bash
npm start
```

Open http://localhost:3000 in your browser.

## Technologies Used

- Node.js
- Express.js
- ValidAxis npm package
- HTML, CSS, JavaScript
